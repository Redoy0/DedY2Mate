      Google account

      One-time setup (about 5 minutes). Google throttles shared upload apps — that's what made the earlier upload crawl. ytbulk uses your own free Google app key, so the upload quota is yours alone.
      1. Open Google Cloud → New project, name it ytbulk, click Create.
      2. Enable the Google Drive API for that project.
      3. Open Google Auth Platform → Get started: app name ytbulk, your email, audience External, finish.
      4. Under Audience click Publish app (or add your Gmail under Test users — test sign-ins expire after 7 days).
      5. Under Clients → Create client → type Desktop app → Create → Download JSON.

      How Drive limits are handled
      • Uploads run alongside downloads, one at a time, resume after network drops and back off when Google says “slow down”.
      • Every upload is checksum-verified. Videos already in the Drive folder are skipped — re-running never makes duplicates.
      • Google allows about 750 GB of uploads per account per day; if reached, start again tomorrow and it continues where it stopped.
